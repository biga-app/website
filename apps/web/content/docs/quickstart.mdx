---
title: Quickstart
description: Install biga, connect to a server, and share a folder live.
---

<Steps>
<Step>

### Install the CLI

<Tabs items={["macOS / Linux", "Windows", "Go"]}>
<Tab value="macOS / Linux">

```sh
curl -fsSL https://raw.githubusercontent.com/biga-app/cli/main/install.sh | sh
```

</Tab>
<Tab value="Windows">

```powershell
irm https://raw.githubusercontent.com/biga-app/cli/main/install.ps1 | iex
```

</Tab>
<Tab value="Go">

```sh
go install github.com/biga-app/cli/cmd/biga@latest
```

</Tab>
</Tabs>

</Step>
<Step>

### Start a broadcast

You need a running biga server. Choose where to broadcast before starting the CLI.

<Tabs items={["Hosted server", "Local server"]}>
<Tab value="Hosted server">

Ask the server operator for its URL and an access key if the server requires one.
From the folder you want to share, replace the example URL with that server's URL.

```sh
biga start --api-url https://biga.example.com
```

For a server that requires a key, set `BIGA_ACCESS_KEY` before you run the command.
See [configuration](/docs/configuration).

</Tab>
<Tab value="Local server">

Follow the [Docker setup](/docs/docker) and choose HTTP mode with `localhost` as the
domain. Wait for the stack to become healthy. From the folder you want to share,
run the broadcast command that the setup script printed. It includes your server
URL and access key.

</Tab>
</Tabs>

biga uploads the folder, prints a link, and streams changes until you stop it.

</Step>
<Step>

### Send the link

Press <kbd>c</kbd> in the live panel to copy it, or <kbd>o</kbd> to open it
yourself. Anyone who can reach the server and has the link can follow along as
you save. A link on `localhost` opens only on the machine running the server.

</Step>
<Step>

### Stop, and pick it back up

Press <kbd>q</kbd> to stop. Running the same start command in the same folder later
**rejoins** the same session, so a link you already shared keeps working, and
only what changed while you were away is uploaded.

</Step>
</Steps>
