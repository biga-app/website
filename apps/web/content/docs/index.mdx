## What biga is

biga streams the files you are working on to a browser tab. You run one command
in a project, share the link it prints, and anyone who opens it follows your
saves as they happen: a file tree, syntax highlighting, search and a timeline
they can step back through.

A screen share sends pixels. biga sends the files themselves, so viewers can
select, search and scroll at their own pace, and nothing is transmitted while you
are not saving.
